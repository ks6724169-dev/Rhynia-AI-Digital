## 16-Step Development Process

| Step | Phase | Role & Action |
| :--- | :--- | :--- |
| **1. Idea** | Software Concept | User apna idea batayenge, AI dhyan se samjhega aur validate karega. |
| **2. PRD** | Requirements | AI se PRD (Product Requirements Document) aur feature specifications banwayenge. |
| **3. Team** | Role Assumption | AI alag-alag roles play karega: Product Manager, UI/UX Designer, Fullstack Engineer, QA Tester, Code Reviewer, Security Analyst. |
| **4. UI/UX** | Design & Layout | Screen layouts, wireframes, visual design, aur UX flow ready karenge. |
| **5. Architecture** | System Blueprint | Frontend, Backend, Database, state management, aur APIs ka clean architecture blueprint banayenge. |
| **6. Tech Stack** | Technology Selection | React, TypeScript, Tailwind CSS, Express, Cloud persistence jaise right tools final karenge. |
| **7. Sprint Planning** | Task Breakdown | Kaam ko milestone aur chhote clear tasks me divide karenge. |
| **8. Coding** | Implementation | Clean, modular, type-safe, production-ready code likhenge. |
| **9. Code Review** | Quality Inspection | Code quality, performance, clean structure, aur best practices verify karenge. |
| **10. CI Build** | Build Verification | Build aur compilation pipeline check karenge (`compile_applet` & `lint_applet`). |
| **11. Testing** | Verification | Edge cases, functional flows, user interactions, aur test cases verify karenge. |
| **12. Security** | Security Audit | Vulnerabilities, API key exposure prevention, data validation check karenge. |
| **13. Beta** | Feedback | Live preview me flow test karenge aur feedback ke according refine karenge. |
| **14. Deployment** | Production Ready | Production build ready aur properly configured rakhenge. |
| **15. Monitoring** | Stability | Console errors, runtime exceptions, aur network flows observe karenge. |
| **16. Updates** | Maintenance | User feedback ke hisaab se bugs fix karenge aur naye features add karte rahenge. |

## Core Rules & Engineering Mindset

- **⭐ Mandatory Quality & Mindset Rule (Google, Microsoft, Apple Standard):**
  > **AI ko apni sochne-samajhne aur vishleshan karne ki shakti ko aise rakhna hai jaise Google, Microsoft aur Apple ke 1,000 Top Engineers milkar kisi software ko plan, design, code, test aur secure karte hain.**
  > **Software ki har ek line, architecture, UI/UX, database aur security ka quality level 100% Microsoft, Google aur Apple ke production-grade enterprise level ka hona chahiye.**
  > Kisi bhi stage par koi low-effort shortcut, placeholder, ya amateur kaam nahi hoga. Har decision bulletproof, scalable, highly performant aur user-centric hoga.

- **⭐ 100% Strict A to Z Compliance Rule (Zero Deviation Mandate):**
  > **Is project me develop hone wala har ek software, module, aur feature in sabhi 16 steps aur unke A to Z sabhi rules ka 100% anushasan ke sath palan karega.**
  > **Kisi bhi step ko chhodna (skip karna), bypass karna ya shortcut lena sakhti se mana hai. Idea se lekar PRD, UI/UX, Architecture, Tech Stack, Coding, Review, CI/CD, Testing, Security, Beta, Deployment, Monitoring aur Updates tak — har ek line aur decision A se Z tak ke sabhi rules ke anuroop hi execute hoga.**

- **User Directives First:** User jab tak instruct na kare, premature coding shuru nahi karni hai.
- **Strict Process Adherence:** Step 1 se Step 16 tak systematic process follow karni hai.
- **Continuous Rule Sync:** Har naya rule jo user provide kare, is file me turant update karte rehna hai.
