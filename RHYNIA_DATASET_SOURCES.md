## 🧭 Master Dataset Acquisition & Curation Protocol
1. **Deduplication & Quality Filtering:** Filter all raw scraped or collected pairs using MinHash LSH and perplexity scoring to eliminate low-quality, repetitive, or noisy text.
2. **Format Harmonization:** Convert all collected multimodal, scientific, and agentic sources into standardized JSONL format (`{"messages": [{"role": "system", ...}, {"role": "user", ...}, {"role": "assistant", ...}]}`).
3. **Privacy & PII Scrubbing:** Strip personal identification information (names, personal emails, phone numbers, API keys, private passwords) before pipeline ingestion.
4. **License Compliance:** Exclusively utilize open-access, research-permissible, and non-commercial/academic permissive corpora (Creative Commons, MIT, Apache 2.0, Open Data Commons).
